# 双灯盘同步输出

底面 IO17，顶面 IO5，各 133 颗 WS2812B，GRB、800kHz，分别持有驱动缓冲。两层采用相同物理灯珠索引，顶面安装朝向及串接顺序需实物核对。亮度上限保持 26/255，新增每层 399 字节像素堆缓冲及驱动对象。

本次不扩展 BLE 协议：轮播、选定灯效及手绘都复制同一帧到两层。原小程序“应用到底面”实际会同步到两层，UI 分层、区域、反向及延迟选项仍只影响预览。没有独立顶层绘画或独立关层控制。

Lighting 任务仍是唯一像素输出者，先发送底层再发送顶层，不保证电气同时刷新。两次传输增加帧耗时；仍使用原 20ms 等待，实际帧率需设备测试。绘画与灯效 ACK 在两个 show 完成后发出。上电初始化先清空两层。

验证：核对顶面是否 133 颗，比较中心/四角索引；测试轮播、选择灯效、手绘、恢复自动及断连保留。新增灯盘增加供电负载，不能把原单层供电验证当作双层供电验收。仅编译和主机测试不代表实物通过。
