# 小程序与固件联动修复

灯效 op6 保留 14/15 字节旧指令，新增 18 字节格式：原 8 字节头之后为 `[effect,speed,brightness,r,g,b,random,layer,region,link]`。layer 为 both/top/bottom；region 为 all/CENTER/corners/UL/UR/LL/LR；link 为 sync/reverse/mirror/delay。所有枚举均从 0 开始。

新增只读 op7 查询：8 字节 A7/v1 头，与绘画会话独立，不重置绘画接收器、命令队列或电机。返回 20 字节：`[A7,1,code,mode,session,seqLo,seqHi,7,十字节灯效参数,elapsedLo,elapsedHi]`。mode 为 0待唤醒、1启动、2自动、3手动效果、4绘画；elapsed 为当前效果进度，单位10ms。查询通知与控制 ACK 分开缓存，控制 ACK 优先。

小程序灯控页连接后轮询，断连立即清除联动状态；编辑或应用中暂停状态覆盖。绘画草稿在3D双面显示，明确应用灯效后清除草稿预览覆盖。方向键按下即发送，400ms后开始150ms间隔连发；松开、取消、后台和断连停止，确认键仍为单次。

固件使用实际毫秒计算效果进度与6秒随机切换。顶面通过输出层镜像重排；手动灯效可对两面分别计算并进行区域掩码。自动随机颜色开关关闭后保持最后颜色。OLED局部亮度与随机色菜单读取共享状态，不再以各自缓存为准。

OLED `Light → Restore Random` 可直接退出手动效果或绘画并恢复随机灯效，不重播启动动画。保持当前亮度及随机颜色开关；命令队列忙时显示 `Retry Random`，可再次确认重试。

OLED `Motor → Exit HOLD/STOP` 切换退出保持策略，默认 HOLD，与小程序共用 `keepRunning` 状态。明确切换属于本地控制，会接管电机；HOLD 时退出保持原方向/速度，STOP 时退出整个 Motor 菜单停止，调速子页面返回不停止。修改策略本身不启动停止中的电机。

手柄确认键为 Xbox A / PS5 叉号，返回键为 Xbox B / PS5 圆圈。返回沿用 OLED 长按返回逻辑：子页面返回上一级，参数弹窗关闭，主菜单不再返回；按下仅触发一次，长按及松开不重复。确认与返回同时按下时返回优先，按住返回期间暂停方向连发。

新增协议需配套更新小程序与固件。主机测试与构建仅验证软件；双面朝向、蓝牙通知在实际手机上的时序、所有区域/联动组合仍需烧录后实机验收。
