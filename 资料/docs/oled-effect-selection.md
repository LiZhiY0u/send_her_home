# OLED 灯效选择

路径：主菜单 Light → Effect。上下键或编码器浏览，短按确认应用；Return 或长按返回。24 行包含返回、Auto Playlist 和 22 种效果，效果编号与小程序保持一致。

本地选择通过 PaintBridge 的同一命令队列交给 Lighting 任务，UI 不直接调用 show。队列满时显示 Retry，需要再次确认；不会覆盖待确认的蓝牙事务。OLED 命令 session=0，不生成 BLE ACK。蓝牙与本地命令均按入队顺序执行，后续命令可替换前面的模式。选效果会退出绘画；离开菜单不会停止灯效。

本地效果默认青色 #57d9ff、速度50%、相对亮度65%，叠加26/255亮度上限。Auto Playlist 恢复现有轮播。IO17和IO5同步输出；不支持独立分层。当前菜单是动作列表，不把光标或复选框当作设备实时状态。Brightness/Color仍是未启用占位页，本次不扩展。

主机测试覆盖22个菜单项到编号0..21的映射、自动轮播入口，以及进入效果子页面；仍需烧录后测试滚动、按键、双层切换、小程序抢占控制与返回保留。
