# 空间灯效预览

## 扩展批次

现有 ID 0..13 保持不变，追加 ID 14..21：向心圆环、双向对撞、偏心涟漪、菱形脉冲、弹跳光块、双臂风车、花瓣开合、对角呼吸。共 22 个可选效果，均可通过 op=6 应用到底面。自动轮播扩展为 20 种（原12种之后追加8种），名义每种12秒，总计240秒。顶部实体输出仍未配置；上下联动只在预览与采样接口中提供。

波浪、海浪、极光已经采用高对比曲线：去底光、压暗中间亮度、不提高峰值。下文的12种及ID上限13是首批历史说明，以本节的22种及上限21为准。

小程序支持离线预览；固件在 ENABLE_LED_STRIP_TEST=1 且 ENABLE_LED_SPATIAL_TEST=1 时，使用 GPIO17 的 133 灯播放 12 种空间灯效轮播，不改变绘画协议。

固件顺序：水平波浪、斜向波浪、正弦光带、海浪叠加、圆形扩散、方框平移、方形扩散、方框旋转、雷达扫描、螺旋光带、四角接力、极光流动。每种 600 帧，每帧等待 20ms（名义 12 秒，实际包含计算与发送耗时），总计名义 144 秒。亮度保持 26/255。绘画期间暂停轮播，恢复自动后从暂停位置继续。

小程序首次点击“应用到底面灯板”后启用本页联动，后续选择效果、颜色及松开速度/亮度滑块自动发送最新参数。设备完成首帧显示后回 ACK，超时或拒绝明确提示，不声称已应用。离开页面停止发送，设备保持最后效果；重进需再次点击应用。区域、灯层及上下联动仅预览，固件未初始化第二条灯带或占用顶部 GPIO。百分比亮度叠加在 26/255 硬件上限内。绘画会替代灯效，恢复自动则返回轮播。固件帧时钟采用固定步进，尚需实物检查实际流畅度与任务余量。

FF12 新增 op=6，14 字节：原有 8 字节头（start/count 为0），后接 effect ID、speed 0..100、brightness 0..100、R、G、B；ID 顺序与小程序 EFFECTS、固件 Effect 枚举相同（0..13）。需先 HELLO 建立会话，序列号递增。FF13 沿用 16 字节 ACK，op=6 表示首帧已应用；旧固件会拒绝或超时，需更新固件。本次不变更 GATT 句柄。

14 个效果：常亮、旋转光线、圆形扩散、水平波浪、斜向波浪、正弦光带、海浪叠加、方框平移、方形扩散、方框旋转、雷达扫描、螺旋光带、四角接力、极光流动。

联动：同步；顶部反向运动；顶部左右镜像；顶部延迟 0.5 秒。径向对称效果的镜像可能没有可见差异；常亮不受联动影响。极光为平滑三角函数叠加的轻量近似，不是物理光学或完整噪声模拟。

采用毫米空间坐标计算柔边亮度，方框和曲线默认软边约 22–26mm，以适配稀疏灯点。灯盘之间无灯区域不会真实发光。3D 顶部朝向仍需实物校准。

进入探索灯光，选择上下联动和全部区域，再切换效果与联动方式。若有绘画草稿，选择任意灯效会清除本页的草稿覆盖，但不会删除绘画草稿或修改设备。

参考：WLED FX.h（https://github.com/wled/WLED/blob/main/wled00/FX.h）；FastLED 连续噪声思路（https://github.com/FastLED/FastLED/blob/master/cookbook/intermediate/noise.md）。本实现未直接复制其源码。
