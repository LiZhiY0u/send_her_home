# 小程序电机控制

首页“电机控制”入口。页面读取设备状态后提供启动/停止、停止状态下换向、0..100%速度滑条（5%步进）和“退出后保持运行”开关。百分比是PWM输出比例，不是实测轴转速。蓝牙连接、状态查询、重新进入页面都不自动启动。

保持策略默认开启，包含返回、微信后台、锁屏、蓝牙断开。保持模式一旦启动可无限持续，断连后需重新连接、设备本地控制或断电才能停止。关闭保持时离页发送STOP；发送失败由固件断连检测/3秒心跳超时停止兜底。不是硬件级安全停机，显示任务或MCU卡死不在软件超时保护能力内。

ESP32 Display任务是电机状态与PWM唯一运行期所有者，初始化仍由启动流程完成。OLED和BLE共用MotorModel；本地明确操作可接管远程状态，本地仅导航不会接管。退出本地Motor菜单仍停止本地拥有的运动，但不停止远程拥有的保持运行。小程序可读出OLED操作，前台约每秒查询一次。并发操作按接收顺序处理，设备回复驱动已应用的命令状态，不提供编码器/电流反馈。

## 协议

复用FF12写入和FF13通知，B8魔数与灯光A7独立，无新增GATT句柄。命令头7字节：B8、01、op、session低/高、sequence低/高。session非0，首次必须QUERY建立通信上下文；查询不改变运行状态。op1查询/心跳、op2字段更新、op3心跳、op4停止。op2额外5字节：run、reverse、speed、keep、mask。mask位1/2/4/8对应run/方向/速度/保持，未选择字段从设备当前状态读取，禁止把缓存run意外带入调速或策略更新。旧的11字节全状态包拒绝。

通知16字节：B8、01、code、op、session低/高、sequence低/高、run、reverse、speed、keep、remote、保留3字节。code0成功，2运行中换向拒绝，3过期会话/序列拒绝。入队失败通过ATT写错误或确认超时体现。每个连接epoch隔离旧队列；重复或逆序命令不执行。只有当前owner session查询才续非保持模式租约。

切换后台立即停止页面轮询。默认保持仍运行；非保持失去租约停止。重连仅QUERY，不重发START。状态未知时“停止/连接后停止”按钮先读取再发STOP，不根据缓存发送完整运行参数。

## 验证边界

主机测试覆盖启动默认值、换向拒绝、PWM调用、重复序号、旧连接丢弃、3秒超时和32位计时回绕；小程序覆盖连接只查询、退出保持/停止、旧离页和旧写回调不能取消新会话，以及调速不重放缓存START。真实手机/电机尚需手动测试。

验收先让电机无负载且可随时断电：查询不转、手动启动与停止、停后换向、滑条、保持开启离页/断连、关闭保持后后台或断连停止、OLED与手机交替操作。不要把模拟测试或编译通过当作机械/电气安全验收。
