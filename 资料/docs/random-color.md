# 随机颜色渐变

OLED：Light 菜单 Random Color ON/OFF。小程序：探索灯光的随机颜色开关，首次点击应用建立设备联动后会发送模式。

每周期5秒：保持1秒，随后4秒线性RGB渐变。使用伪随机调色板序列（7种高饱和颜色），不依赖网络，不保存掉电状态。上下灯盘同色，不改变灯效速度或亮度上限。OLED开关只改变颜色模式，不重置当前效果；BLE应用完整灯效参数时重置该效果和颜色周期。关闭恢复已选固定色，点选小程序色块也关闭随机模式。手绘直接输出画面，不套用随机色。

自动轮播时开启随机色替代轮播的预设颜色；关闭恢复原轮播配色。界面开关代表各自最后操作，不是跨端实时状态；另一端可覆盖设备。小程序预览与设备以各自启动时刻计时，不保证颜色相位精确同步。

FF12 op6保留14字节固定色包，新增可选第15字节（0固定/1随机）。旧包默认固定，非法模式拒绝；新包需新版固件。绘画协议和五向键不变。颜色计时使用毫秒时间，不随灯效速度滑块改变。
