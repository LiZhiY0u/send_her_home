# OLED 亮度滑条

Light → Brightness，上下键或旋转编码器每次5%，0..100%，确认或长按返回并保留。初始OLED显示100%，不是跨端设备状态读回。100%对应原有26/255亮度上限；不提高峰值功率设置。

通过同一灯光命令队列下发亮度，不改变灯效、速度或随机颜色模式；队列满时显示Retry且不更新本地数值。作用于IO17和IO5的轮播、选定效果及手绘。驱动亮度为26*百分比/100，因此实际有27档整数输出，部分相邻5%刻度可能同档。

手绘保留额外399字节静态原始画面，以便0%恢复时重绘，不依赖驱动缓冲反向恢复。蓝牙完整灯效指令中的亮度会覆盖本地输出；本地更换效果不重置亮度。小程序已有滑条，本次不改BLE协议。

需要实物验证：0%熄灭、100%原上限、随机色及轮播连续性、手绘灭灯后恢复、两层一致性。未增加掉电保存。
