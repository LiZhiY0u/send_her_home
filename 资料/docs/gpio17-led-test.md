# GPIO17 灯带测试（当前 133 颗）

临时默认启用 `Configs/LightingTestConfig.h` 的 ENABLE_LED_STRIP_TEST=1。复用原 Lighting 任务，不新增 RTOS 任务。当前 133 颗 WS2812B/GRB 800kHz 在 GPIO17 上单链级联；不再采用坐标方案的 A/B 两路输出。供电按灯带额定要求，GND 与 ESP32 共地。此前四灯测试用户反馈通过。

默认已切换到[照片映射空间灯效](led-spatial-validation.md)，青色扩散圆环与橙色旋转直线交替。将 ENABLE_LED_SPATIAL_TEST 设为0，可恢复以下三段映射验证灯效，末尾全灭 1 秒后重复，一轮约 21.64 秒：

1. 区域点名：中心白、左上红、左下绿、右下蓝、右上紫，每区独立亮 1 秒。
2. 四角同步追逐：四块各亮相同局部编号，沿各板串接顺序走完 25 颗，每步 200ms；沿用各角标识色。中心熄灭。
3. 全链追逐：仅一颗白灯从第 1 颗走到第 133 颗，每步 80ms。

实际链路由用户照片并确认：中心（1→2）→左上（3→4）→左下（5→6）→右下（7→8）→右上（9→10）。零基偏移分别 0、33、58、83、108。四角局部顺序暂视为旋转对应，需实物验证；本阶段未将逐颗编号映射到精确 XY 坐标，不宣称实现空间直线/圆环效果。

亮度 26/255（约 10%），只是软件亮度设置，不是硬件限流保护。此测试不执行 133 颗同时全白，区域点名的中心阶段会同时点亮中心 33 颗白灯，请确保供电能力。

测试期间原 GPIO19 彩虹演示暂停；将 ENABLE_LED_STRIP_TEST 改为 0 后重新编译烧录可恢复。UI、蓝牙和电机逻辑不改。此次未自动烧录或执行实物点亮。

主机测试验证颜色、灯号、熄灭和循环；实际供电、颜色顺序与波形仍需用户烧录验收。若红绿互换，需核对灯带的 RGB/GRB 型号配置。
