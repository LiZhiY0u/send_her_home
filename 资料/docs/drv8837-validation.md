# DRV8837 电机驱动适配

接线：IN1 / MOTOR_PIN_1 为 GPIO4，IN2 / MOTOR_PIN_2 为 GPIO16，H1 接直流电机。nSLEEP 在硬件上接 VCC，无软件睡眠控制。取消旧 TB6612 独立 GPIO17 PWM。

`DRV8837.h` 中 Motor 构造不访问硬件；AppTasks 启动时调用 begin，将两路输出设置为零。使用独立 LEDC 通道 1、2，1kHz、8 位 PWM。

- drive(1..255)：IN1 PWM、IN2 低；负值方向相反。
- drive(0) / stop()：两路低，滑行停止。
- brake()：两路高，短路制动，不等于滑行停止。
- 超出范围的速度限幅；初始化前的控制调用不输出。

控制仅允许单一任务拥有，不可从 ISR 调用。切换方向时先关闭两路，但不实现电机减速、反转等待或电流限制；正式接入 UI 前需要结合负载设计运动策略。没有保留阻塞式 drive(speed, duration)，当前项目没有调用者。

此次仅替换驱动，没有增加电机任务或 UI 动作，没有烧录或实际转动电机。主机测试不能证明 PWM 波形、供电能力、堵转保护或电机方向。

实机测试前确认 VM 实际电压、电机堵转电流及电源能力。建议先不接电机，用示波器验证两路初始化为低和 PWM 控制，再以限流电源、小占空比、卸载状态测试。正反转物理方向取决于 H1 接线。
