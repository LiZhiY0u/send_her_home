# Motor 页面

主菜单第五项 Motor。列表第一行 [ Motor ] 用于返回，随后是 Run OFF/ON、Dir FWD/REV、Speed 百分比。OLED 使用现有英文字体。速度子页显示百分比和进度条，上下每次调整 5%，范围 0..100%，确认返回。

初始停止、正转、速度 30%。运行时方向修改被忽略；停止后才可切换。速度子页实时调速，返回电机列表继续当前运行；退出整个 Motor 页面、跳往其他页面或 OpenRoot 时停止。重新进入仍为停止，速度和方向保留到断电。

PWM 百分比不是闭环实际转速，没有堵转检测、连接断开自动停机或独立急停。遥控断连不自动停止，电机可能继续运行；测试必须能切断供电。没有自动烧录、启动电机或推送。

主机验证：状态限幅、运行禁止换向、零速输出；真实 OLED 页面流程（模拟电机输出）验证启动、运行进入速度页、返回保持运行、退出停止和重新进入不重启。主机测试不证明 OLED 实际排版或电机电气行为。

2026-10-11 用户反馈“测试正常”，Motor UI 与电机控制通过用户实机测试。随后反馈 100% 时感觉速度偏慢，暂时接受当前实现；尚未测量 VM、电机端电压或实际转速，不能据此确认额定转速和供电能力。

后续电气验证建议：确认电压和电流条件，卸载、限流供电，从 10% 速度开始验证。不要在有危险机械负载时首次测试。
