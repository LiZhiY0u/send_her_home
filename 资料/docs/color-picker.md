# 共用调色面板

灯控与画画页保留快捷色块，并新增“自定义颜色”按钮，使用同一个原生小程序组件，无新增 npm 依赖。

支持色盘（角度选色相、半径选饱和度）、HSV 三滑条、HEX 3/6位输入和可展开RGB整数输入。RGB范围0..255；HEX允许省略#。颜色明度是RGB颜色的一部分，不是灯带驱动亮度，不改变固件26/255上限。

调色时只发本地preview事件；灯控本地更新3D颜色，确认后且本页已开启设备联动才发送BLE。取消恢复打开时的颜色和随机模式；选定自定义颜色关闭随机色。设备待发送请求使用当时参数快照，避免取到未确认预览。

画画页只改变未来笔触颜色，不重新着色已有画面，也不因选色而发送整幅画；取消同时恢复先前橡皮状态。返回后台时取消未确认选择。

组件支持横竖屏，色盘异常时仍可用滑条和输入框。关闭后阻止旧输入/测量回调继续修改颜色。页面使用相对路径注册组件，避免当前开发者工具中组件 WXML 注册为 undefined、继而重复渲染父页面模板的问题。

弹窗打开时隐藏底层原生 Canvas，避免画板或 WebGL 覆盖弹窗；关闭后重新绘制原画面。开发者工具已验证竖屏画画页弹窗显示、色盘选色及取消恢复。Node测试覆盖颜色换算、坐标、输入校验、取消、确认、待发快照隔离和画布恢复；手机真机、键盘及横屏实际触摸仍需验证。
