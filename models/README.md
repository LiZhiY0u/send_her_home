# 项目模型

本目录保存展示柜使用的四组模型，保留提供时的文件名和全部对应格式。

| 模型 | SolidWorks 零件 | STL 网格 | SWP 宏文件 |
|---|---|---|---|
| 电机齿轮V2 | [SLDPRT](电机齿轮V2.SLDPRT) | [STL](电机齿轮V2.STL) | 未提供 |
| 四角无垫高V1 | [SLDPRT](四角无垫高V1.SLDPRT) | [STL](四角无垫高V1.STL) | [SWP](四角无垫高V1.swp) |
| 四角无顶V3 | [SLDPRT](四角无顶V3.SLDPRT) | [STL](四角无顶V3.STL) | [SWP](四角无顶V3.swp) |
| 转盘V3 | [SLDPRT](转盘V3.SLDPRT) | [STL](转盘V3.STL) | [SWP](转盘V3.swp) |

- `.SLDPRT`：SolidWorks 原始零件文件，用于查看和修改模型。
- `.STL`：网格导出文件，可导入切片软件准备打印。
- `.swp`：随模型提供的 SolidWorks 宏文件，作为配套源文件归档。

共 11 个模型文件，从提供的 `figure_display_case/model` 目录直接复制并核对 SHA-256；没有重新生成、修改尺寸或运行宏。目录中其他模型及旧版本未纳入此次归档。
