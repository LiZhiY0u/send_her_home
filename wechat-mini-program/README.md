# FigureCase 微信小程序

[send_her_home](https://github.com/LiZhiY0u/send_her_home) 的手机端，通过 BLE 控制 ESP32 展示柜。运行时名称及广播名仍为 `FigureCase`。

## 页面与功能

| 页面 | 功能 |
|---|---|
| 遥控首页 | 连接/断开、五向按键，进入灯效、绘画、电机 |
| 探索灯光 | 双层 3D 预览，22 种效果，颜色/亮度/速度及随机渐变，确认后联动实物 |
| 以光作画 | 133 点物理灯位画布，软边画笔、颜色/笔宽、橡皮、清空与设备同步 |
| 电机控制 | 设备状态读取、启停、停止后换向、速度滑条、退出保持开关 |

3D 页支持竖屏上下分区、横屏模型在左/控制在右，控制区独立滚动。绘画页横屏为左画布/右工具；旋转后重绘草稿并更新触摸坐标。电机页也支持横屏布局。真机布局和性能仍需按机型验收。

## 导入与运行

1. 用微信开发者工具导入本目录。
2. 使用自己的小程序 AppID；仓库示例值为 `touristappid`，本地配置不要被示例覆盖。
3. 如需 3D 预览，使用已有 Node/npm 安装工程依赖：

```powershell
# 从仓库根目录执行
npm.cmd ci --prefix .\wechat-mini-program --ignore-scripts --no-audit --no-fund
npm.cmd test --prefix .\wechat-mini-program
```

4. 在微信开发者工具选择“工具 → 构建 npm”，再点击“编译”。
5. 实物控制需要对应的新固件，由用户手动烧录后在手机上连接。

依赖固定为 `threejs-miniprogram@0.0.8`（MIT，内部 Three.js r108）。`node_modules/`、`miniprogram_npm/` 为生成目录，不入库。上述命令安装的是工程依赖，不要求额外全局 SDK；不要为了本工程重复安装已有的开发环境。

蓝牙功能用真机验证，模拟器画面或 Node 测试不能证明实物已收到指令。3D 报 npm 模块不存在时先构建 npm；WebGL 失败会显示错误提示。3D 隐藏时停止动画、退出释放资源，30fps 仅为预览目标上限。

## 灯效控制

先在“探索灯光”选择效果、颜色、速度及亮度，再点击“应用到底面灯板”。应用成功后，本页后续效果/颜色选择及滑条松开会自动发送；离开页面停止自动发送，设备保留最后效果，重新进入需再次点击应用。

**按钮虽然仍写“底面”，当前固件实际复制到 IO17 底面与 IO5 顶面，每层 133 颗，共 266 颗。**

- 22 种可选灯效，固件另有 20 种自动轮播。
- 小程序灯层、区域、同步/反向/镜像/延迟只控制预览，尚未发送到实物。
- 固件亮度上限 `26/255`；100% 是相对该上限，并非全功率。
- 随机颜色开关每周期保持约 4 秒、渐变 1 秒；使用伪随机调色板。点固定色块会关闭随机模式。
- 预览盒体 200×200×300mm 是示意模型，不模拟真实照度、反射或空气中的光柱。
- 灯光选项没有跨端完整状态读回；页面显示不保证与 OLED 最后操作一致。只有收到相应应用确认才提示已应用。

## 手绘

从首页“以光作画”直接进入，不依赖 3D 页面。默认软画笔直径 24mm，可调 10–60mm；笔画按线段采样、邻近灯点渐变补光，不要求手指精确经过每颗灯。

点击“连接并同步绘画”后发送完整帧，设备确认已显示后才提示同步。当前上下灯盘同步绘画，没有独立顶层绘画。没有灯珠的空隙不能真实连续发光。

退出或断连保留最后完整画面，“恢复自动灯效”才恢复轮播。草稿只存在本次小程序运行内，非持久存储；重新进入需手动开启同步。

## 电机与退出策略

进入电机页先读取 ESP32 状态，**连接/查询/重进不自动启动**。页面支持：

- 手动启动、停止，以及“停止 / 连接后停止”。
- 仅在停止状态下切换正反转。
- 速度 0–100%，5% 步进；表示 PWM 输出比例，不是实测转速。
- 与 OLED 共用设备状态，前台约每秒读取。调速或策略更新不会附带缓存启动指令。

**“退出后保持运行”默认开启，包含返回、后台、锁屏和蓝牙断开。启动后可能持续运行，请保证可重新连接、本地操作或断电停止。**

关闭保持时离页发送停止，固件在断连或约 3 秒心跳超时后停止作为兜底；此保护依赖任务正常运行，不是硬件急停。断连时不能把手机动画当作实际运行状态。固件上电停止，初始速度设置 30%，策略不保存掉电前运行状态。

## BLE 接口

共用一条连接和串行写队列，页面不会各自初始化另一蓝牙栈。

- 广播名：`FigureCase`
- Service：`0000FF10-0000-1000-8000-00805F9B34FB`
- FF11：五向键写入
- FF12：扩展命令写入
- FF13：状态通知/读取

后两项完整 UUID 与服务相同，分别将 FF10 替换为 FF12 / FF13。

| 五向键 | 数据 | 当前 UI 映射 |
|---|---|---|
| 上 / 左 | `0x01` / `0x03` | 上一项 |
| 下 / 右 | `0x02` / `0x04` | 下一项 |
| 确定 | `0x05` | 短按确认 |

A7 包用于绘画及灯效，B8 包用于电机；两者有独立会话/序列，不能混用。实现见 `painting/protocol.js`、`painting/sender.js`、`motor/protocol.js` 和 `motor/client.js`。
