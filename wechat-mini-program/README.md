## 导入

用微信开发者工具导入本目录。`project.config.json` 当前使用测试 AppID；真机调试或发布前，请换成自己的小程序 AppID。

## 3D 灯阵离线原型

## 新增：底面软画笔

原遥控页可直接进入“底面灯板 · 实时绘画”，先离线画画（不依赖3D npm包）。默认24mm软画笔，支持颜色、宽度、橡皮擦、清空；附近灯点自动渐变补光，快速划动按线段补齐。

要控制实物，先由用户手动更新本次ESP32固件，再点“连接并同步绘画”。只控制GPIO17的133灯，收到设备应用确认才显示已同步。退出/断连保留最后完整画面，主动点“恢复自动灯效”才恢复动画。原五键与绘画共用蓝牙连接。详细步骤和边界见 资料/docs/led-paint-validation.md。

### 3D 原型说明

原遥控页下方点击“灯阵实验室”。上下各 133 颗灯，支持拖动旋转、双指缩放、层/区域选择、常亮/旋转光线/扩散圆环、颜色/亮度/速度、同步/反向与暂停。此页面不连接或发送 BLE；原遥控连接逻辑保持不变。

在本目录使用已有 Node/npm：

```powershell
npm.cmd ci --ignore-scripts --no-audit --no-fund
npm.cmd test
```

随后在微信开发者工具菜单“工具 → 构建 npm”，编译并进入预览页。依赖固定为 MIT 许可的 `threejs-miniprogram@0.0.8`（内部 Three.js r108）；node_modules 和 miniprogram_npm 是忽略的生成目录。构建 npm 不需要安装额外全局 SDK。现有 AppID 配置保留，不用覆盖。

如提示 npm 模块不存在，先完成“构建 npm”再编译。WebGL 不可用会显示返回入口；Android/iOS 真机显示及性能尚待验证。隐藏停止动画、退出释放资源；30fps 是目标节流上限，并非实测性能承诺。

200×200×300mm 为模型示意尺寸，盒高及顶部方向未做实物校准。预览不是实际照度仿真，也不代表灯阵已执行。灯位来源及 SHA256 见 lighting/DATA-SOURCE.md。该原型没有云端、实际灯控协议、单灯涂色和真实手办模型。
